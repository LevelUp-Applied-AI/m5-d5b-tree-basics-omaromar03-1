# Basic Skills Exercise 5B - Tree Modeling Fundamentals

This is a Unit 5, Week B exercise for the Applied Artificial Intelligence and Machine Learning Systems curriculum in AI.SPIRE.

---

## Overview

In this exercise, I implemented basic tree models using the scikit-learn library:

- Decision tree for classification
- Feature significance extraction
- Random forest with balanced class weights

The objective is to understand how tree models handle nonlinear relationships and class imbalances.
